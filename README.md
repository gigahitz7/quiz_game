# 🐍 파이썬 기초 퀴즈 게임

파이썬 기초 개념을 재미있게 복습할 수 있는 콘솔 퀴즈 게임입니다.

## 📖 프로젝트 개요

변수, 자료형, 함수 등 파이썬 기초 개념을 4지선다 퀴즈로 풀어보는 콘솔 프로그램입니다.
퀴즈를 풀고, 직접 추가하고, 최고 점수를 기록할 수 있습니다.

## 🎯 퀴즈 주제와 선정 이유

**주제:** 파이썬 기초

**선정 이유:** 이번 과제에서 배운 변수, 자료형(int/str/list/dict), 조건문, 함수 개념을 스스로 점검하고 복습하기 위해 선택했습니다.
